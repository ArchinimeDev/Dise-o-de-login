## 📖 Descripción

Interfaz de autenticación (Login y Registro) construida desde cero con **HTML, CSS y JavaScript vanilla**, sin frameworks ni librerías externas más allá de los iconos.

El diseño cuenta con un **panel deslizante animado** que alterna entre los formularios de inicio de sesión y registro, etiquetas flotantes en los inputs, validaciones en tiempo real y botones de **login social** (Google, Facebook, LinkedIn y GitHub).

Ideal como plantilla base para cualquier proyecto web que necesite autenticación con un diseño moderno y profesional.

---

## 🚀 Características Principales

| Característica | Descripción |
|---|---|
| 🔄 **Panel deslizante animado** | Transición suave entre Login y Registro con CSS puro |
| 📝 **Etiquetas flotantes** | Los labels se mueven al escribir (estilo Material Design) |
| ✅ **Validación de formularios** | Nombre, correo, contraseña y términos, con mensajes de error claros |
| 💾 **Persistencia con localStorage** | Los usuarios registrados se guardan y sobreviven al recargar la página |
| 🎨 **Login social** | Botones para Google, Facebook, LinkedIn y GitHub con sus colores oficiales |
| 📱 **100% Responsive** | Se adapta a móviles, tablets y escritorio |
| 🌈 **Variables CSS** | Paleta centralizada con `:root` para personalización rápida |
| 🧩 **Código comentado** | Fácil de entender y extender |

---

## 🛠️ Tecnologías Utilizadas

- **HTML5** — Estructura semántica
- **CSS3** — Animaciones, transiciones, Flexbox, variables y media queries
- **JavaScript (ES6+)** — Validaciones, manipulación del DOM y `localStorage`
- **Boxicons** — Iconos de alta calidad (vía CDN)
- **Google Fonts** — Tipografía *Poppins*
- **GitHub Pages** — Despliegue del demo en vivo
